# Security

The Nodes Wars repository is private. This document is an internal reference for future self more than a public disclosure policy.

## Threat Model Summary

- The PWA runs untrusted on the player's phone. Never trust client provided state.
- The PHP API is the strict authoritative source of truth for match outcomes, XP, coins, and level.
- LoRa mesh traffic is broadcast and observable. Assume packet inspection by anyone on the mesh.
- Signatures use Ed25519. Player keys are provisioned server side and pinned client side.
- Match session keys are ephemeral, generated by the game master, and stored encrypted server side.

## If Something Looks Wrong

- Rotate the affected key or credential immediately.
- If a Sentry alert points at a signature verification failure spike, investigate before the next deploy.
- If a leaked secret is committed, rewrite history, force push, and rotate the secret. Do not just delete the file.

## Reporting

For a private repo with a single maintainer, "reporting" means: open a private issue tagged `security`, or if the repo is ever opened up, email the maintainer directly.
